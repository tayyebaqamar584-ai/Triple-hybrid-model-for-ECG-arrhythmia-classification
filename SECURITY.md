# Security Policy

Please do not report credentials, private recordings, or other sensitive material in
public issues. For a suspected security or privacy issue, contact the repository
maintainer through the private contact mechanism configured for the GitHub account.

Do not commit `.env` files, access tokens, private keys, patient data, PowerLab data,
or local virtual environments. Removing a file from the working tree does not remove
it from Git history; suspected historical exposure requires a separate history audit
and, where appropriate, history rewriting.
