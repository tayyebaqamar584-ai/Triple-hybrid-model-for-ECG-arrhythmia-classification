# Contributing

Thanks for helping improve this ECG classification project.

## How to contribute

1. Fork the repository and create a feature branch.
2. Make focused changes and keep the scope narrow.
3. Run the test suite before submitting a pull request.
4. Open a pull request with a clear description of the change and its motivation.

## Development checklist

- Ensure any new code is covered by relevant tests where possible.
- Keep documentation up to date when behavior or usage changes.
- Avoid committing local secrets, API keys, or large generated artifacts.
